Call the `end_of_day_report` tool to generate and save an end-of-day report. This includes tickets completed today, in-progress items, code changes analysis, overdue/critical flagging, and carry-forward items.

If the user provided arguments: $ARGUMENTS — treat them as non-ticket work and pass as the `extra_work` parameter (e.g. "design review 2h, team sync, code review for PR #45").
