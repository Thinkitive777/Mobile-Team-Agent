# Presentation

Two standalone files. No internet needed, no external requests, nothing hosted anywhere.
Double-click to open in any browser, or attach to an email.

| File | What it is |
|---|---|
| `deck.html` | 13 slides for the meeting |
| `one-pager.html` | The leave-behind. Also prints cleanly to A4 (Cmd/Ctrl+P) |
| `speaker-notes.md` | What to say on each slide, timing, and answers to likely questions |

## Presenting `deck.html`

| Key | Does |
|---|---|
| `→` `space` or click | next slide |
| `←` | previous |
| `F` | fullscreen |
| `O` | slide overview — click any slide to jump |
| `T` | switch light / dark |
| `Esc` | close overview |

The URL keeps the slide number (`deck.html#7`), so a reload does not lose your place.
It works on a phone or tablet too — swipe left and right.

Both files follow your system light/dark setting. For a projector, press `T` to force light.

## Making a PDF

Open either file and print to PDF (Cmd/Ctrl+P). The deck prints one slide per landscape page;
the one-pager prints as A4 portrait.

## Sharing

Email the files, drop them on any internal server or shared drive, or commit them. Each is a
single self-contained HTML file — no assets, no fonts to download, no tracking.
